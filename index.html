Technical Architecture

MandiFlow Orchestration System — SIH 2026

Detailed design mapping directly to SIH Problem Statement 26032 & Presentation Deck

🖥️ Technology Stack (Slide 3)

  • Frontend: React.js / Modern Progressive Web App (PWA) with offline caching
  • Backend: Node.js + Express.js High-Throughput REST APIs
  • Database: PostgreSQL / MySQL with ACID transactional booking locks
  • Communication: Interactive Voice Response (IVR) + SMS Gateway integration
  • Deployment: Cloud Containerized Architecture with horizontal auto-scaling

⚙️ Capacity-Aware Scheduling Engine

  • Dynamic Bottleneck Math: Slot_Capacity = min(Assaying_Rate, Weighbridge_Rate, Unloading_Rate)
  • Virtual Queuing: Zero physical congestion; geo-fenced ETA notifications
  • Dynamic Rescheduling: Buffer windows absorb delays without blocking on-time farmers
  • Offline Resiliency: Local IndexedDB persistence with automatic sync upon reconnect

📞 Omnichannel Inclusivity (Slide 2 & 4)

  • IVR Voice Menu: 1: Slot Booking, 2: Token Details, 3: Queue Position, 4: Payment Status
  • Basic Phone Fallback: SMS token confirmation, gate arrival alerts, and DBT transfer receipts
  • Regional Languages: English, Hindi, and Punjabi voice & text support
  • Aadhaar / Land Records: Auto-verifies landholding against MP/HP Bhulekh records

📚 References Cited in Project (Slide 6)

  • e-NAM Mobile App: National Agriculture Market standard integration
  • E-Samridhi: NAFED pulses and oilseeds procurement protocol
  • DFPD / FCI: Food Corporation of India centralized grain handling
  • AGMARKNET: Real-time Mandi price & arrival intelligence network
  • Tribune India: Study on portal glitches and waiting queue bottlenecks
